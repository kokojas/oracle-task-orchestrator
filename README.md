# oracle-task-orchestrator

Resumable batches for presentations, images, video and research.

## What it does

Create work items, preview an Oracle batch, execute or resume it, and inspect per-item artifacts. See `SKILL.md` for the workflow. Browser execution needs an installed Oracle CLI and authenticated target services. Set `ORACLE_CHATGPT_URL` to the project URL when project isolation is required.

## Repository

- `SKILL.md`: usage and behavior

Source files are in `scripts/`, `references/`, `agents/` or `static/` where applicable.

## Notes

Commands that use external services require your own authenticated account. Review generated outputs before sharing them.
